# devref

A loose warehouse of reusable, copy-paste-ready instruction fragments for agentic development work.

This repository is **not** a standard, policy framework, specification, requirements set, or general development ruleset. Nothing here is active by default. The contents are simply useful pieces of promptcraft collected for selective reuse when drafting project briefs, issue prompts, research tasks, review instructions, or autonomous execution runs.

Think of it as a toolshed: some tools are complementary, some overlap, some contradict each other, and some are only useful in unusual circumstances. Choose the pieces that fit the job.

## Ground rule

The existence of an instruction fragment in this repository gives it no authority over any project. Copying or explicitly incorporating a fragment into a brief is what makes it relevant to that work.

In particular, rules or terminology from one project must not silently become constraints on another project merely because an agent has seen or remembered them.

## Contents

The initial library is organized loosely by theme for retrieval convenience. The categories are shelving, not an ontology; fragments should remain self-contained enough to paste into a fresh brief without requiring the rest of this repository.
